# Mini-Marché 3D

Application Android du jeu **Mini-Marché 3D**, créée avec Capacitor.

## Télécharger l’APK

1. Ouvrir l’onglet **Actions**.
2. Ouvrir la dernière compilation verte **Construire APK Android**.
3. En bas de la page, télécharger **Mini-Marche-3D-APK**.
4. Décompresser le fichier ZIP, puis installer `Mini-Marche-3D.apk` sur Android.

## Fonctionnement

Le jeu HTML est conservé dans `source/mini-marche-3d.html.gz.b64`. L’action GitHub le restaure, ajoute le conteneur Android, puis produit automatiquement un APK installable.

## Identité Android

- Nom : `Mini-Marché 3D`
- Package : `com.tikowikofamily.minimarche`
